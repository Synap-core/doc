# CRM Connector UX Spec

How connector-powered actions surface in the CRM UI. Each action maps to a specific backend call.

---

## Settings — Connected Accounts

**Route**: `/settings` → "Connected Accounts" section

A list of the user's active `SyncConnector` connections:

```
Google Contacts   ✓ Connected   Last sync: 2 min ago   [Sync now]  [Disconnect]
Gmail             ✓ Connected   Last sync: 5 min ago   [Sync now]  [Disconnect]
Google Calendar   ✗ Not connected                       [Connect]
```

- **Connect** → calls `syncConnectorRegistry.get("nango").createSession(userId, provider, workspaceId)` → opens Nango OAuth redirect in modal
- **Disconnect** → calls `NangoConnector.revokeConnection(connectionId)`
- **Sync now** → calls `POST /api/hub/connectors/trigger-sync` → schedules a `FEED_SOURCE_EXECUTE` job immediately
- Shows sync status from `entity_external_links` (last sync timestamp per provider)

**Setup prompt** (shown if Nango not configured on pod):  
`"Run eve nango init on your server to enable account connections."`

## Company detail page

### Find contacts at this company
**Trigger**: "Find leads" button in company header  
**Backend**: `ApifyProvider.enrich({ actorId: "curious_coder/linkedin-company-search", params: { company: entity.title, domain: entity.properties.website } })`  
**Result**: each returned person → created as a `lead` entity with `crmStatus: "lead"` via proposal → appears in Leads Feed  
**UI feedback**: spinner → "12 potential leads found — review in Leads Feed"

### Enrich company
**Trigger**: "Enrich" button in company detail toolbar  
**Backend**: `ApolloProvider.enrich({ endpoint: "organizations/enrich", params: { domain: entity.properties.website } })`  
**Result**: proposal updating `revenue`, `companySize`, `fundingStage`, `techStack`, `employeeCount`  
**UI feedback**: proposal badge on company card → user reviews in inline diff view

### Link Google Drive folder
**Trigger**: "Link Drive folder" in company detail → file picker  
**Backend**: Google Drive OAuth via NangoConnector → folder entity linked to company via `relations.create`  
**UI feedback**: "Drive" tab in company detail showing folder contents (document entities)

## Contact detail page

### Enrich contact
**Trigger**: "Enrich" button in contact header  
**Backend**: `ApolloProvider.enrich({ endpoint: "people/match", params: { name: entity.title, organization_name: entity.properties.company, domain: ... } })`  
**Result**: proposal updating `email`, `phone`, `linkedinUrl`, `title`, `icpScore`  
**UI feedback**: inline diff showing current vs proposed values — one-click approve

### Find email
**Trigger**: shown only when `email` property is empty  
**Backend**: same Apollo `people/match` call, filtered to email field  
**UI feedback**: "Found: alice@acme.com (confidence 87%)" — click to accept

### Link conversation
**Trigger**: "+" in contact thread panel  
**Options**: Gmail thread, Slack conversation, WhatsApp (if connected)  
**Backend**: creates a channel link between the external channel and this contact entity  
**UI feedback**: conversation appears in contact thread inline

## Pipeline (kanban)

### Import from Google Contacts
**Trigger**: "Import" button in pipeline toolbar  
**Backend**: triggers `NangoConnector.fetchRecords(connectionId, "google-contacts-contact")` → batch-creates person entities with `crmStatus: "lead"`  
**UI feedback**: "47 contacts imported — review new leads"

### Stuck deal indicator
**Trigger**: automatic — any contact unchanged for >14 days in the same `crmStatus`  
**Backend**: `automation-pattern-detect` cron worker (runs daily) flags stuck deals  
**UI feedback**: amber dot on kanban card + tooltip "Stuck 16 days — Eve suggests a follow-up"  
**Action**: click amber dot → opens Eve suggestion panel with draft follow-up message

## Leads Feed

The unified surface where all enriched lead entities appear.

### Source filter chips
`All` · `Google Contacts` · `LinkedIn` · `Apollo` · `Apify` · `Manual`  
Filters by `entity_external_links.provider`

### Lead card
Each card shows:
- Name + company
- Source badge (e.g. "Apollo" in blue)
- Enrichment confidence score (0–100%)
- `crmStatus` pill — editable inline
- `icpScore` bar

### Batch proposal review
When AI proposes multiple lead moves or new contacts, they appear as a grouped proposal:
```
Eve suggests 8 actions  [Review all]  [Approve all]  [Dismiss]
  ↳ Move Acme Corp → Qualifying
  ↳ Add 3 contacts from LinkedIn import
  ↳ Update ICP score for 4 stale contacts
```

## Find Leads page

Full-page prospecting UI backed by Apify + Apollo.

### Query builder
Fields: Industry · Company size · Location · Title keywords · Technology stack  
**Backend**: `ApifyProvider.enrich({ actorId: "curious_coder/linkedin-company-search", params: queryFields })`

### Results
- Table view of returned companies/people
- Each row: name, company, title, location, confidence score
- "Add to pipeline" → creates entity with `crmStatus: "lead"` + triggers Apollo enrichment  
- "Add all" → batch create + batch enrich → batch proposal in Leads Feed

### Saved searches
User can save a query → runs weekly as a background Apify job → new results appear in Leads Feed automatically
