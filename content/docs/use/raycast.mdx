The Synap extension for [Raycast](https://www.raycast.com) lets you search and write to your pod from the launcher
and from Raycast AI.

## Connect Raycast to your pod

Install the Synap extension in Raycast. Then, with the CLI connected to your pod, run:

```bash
synap connect raycast
```

The CLI creates a dedicated agent key for Raycast on your pod and stores it where the Synap extension reads it. By
default the key covers the whole pod; `--workspace <id>` limits it to one workspace.

### Optional: the full MCP tool set

```bash
synap connect raycast --with-mcp
```

This also adds your pod's MCP server to Raycast's MCP configuration, through the `mcp-remote` bridge (Raycast's
native MCP support runs local processes only). The tool names overlap with the extension's own commands.

## Generate script commands

```bash
synap raycast generate
```

(a hidden command, not listed in `synap --help`) writes a Raycast Script Command for each enabled capability on your pod. Each script calls
`synap capability run <verbId>` with the arguments the capability declares.

## If something does not work

- `synap doctor` checks that the key works and that the workspace exists on this pod.
- `synap pods use <name> --surface raycast` switches only Raycast to another saved pod.
